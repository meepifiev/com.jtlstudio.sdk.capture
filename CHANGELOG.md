# Changelog

## [1.0.0] - 2026-09-24

Первый выпуск.

- Скриншоты и видео для страниц площадок сразу на всех языках активной конфигурации: один прогон, одинаковые кадры, разный текст.
- Пресеты размеров под Яндекс Игры, YouTube Playables, Google Play, App Store и RuStore, размеры правятся в окне.
- Запись видео встроенным кодировщиком Unity в MP4 со звуком игры, без внешних зависимостей.
- Горячие клавиши в Play Mode на скриншот и на старт или стоп записи.
- Скрытие лишнего на время съёмки: объекты по имени и слои целиком.
- Переключение языка идёт через JTL SDK, а если у игры своя локализация, подставляется свой метод через `CaptureLanguages.Switch`.
